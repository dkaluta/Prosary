# Prosary Prayers — the devotion repository

Static site for `https://prayers.prosary.app`: a catalog of shareable `.prosaryprayer`
bundles (the format in `../Shared/ARCHITECTURE.md` § Content bundles). No build step — the
page renders `index.json` client-side; Vercel serves the directory as-is (**Root Directory
`Repository`**, framework preset "Other", no build command; production tracks `main`; DNS:
Namecheap CNAME `prayers → cname.vercel-dns.com`).

## Catalog format (`index.json`)

```json
{
  "prosaryRepository": 1,
  "bundles": [
    {
      "id": "repo.<username>.<name>",
      "name": "Display name",
      "author": "<username>",
      "languages": ["la", "en"],
      "description": "One or two sentences.",
      "file": "bundles/repo.<username>.<name>.prosaryprayer"
    }
  ]
}
```

- **Ids are `repo.<username>.<name>`** — the `repo.` prefix is what the apps key their
  "Repository" tag on, and it can never collide with compose-authored ids (whose shape forbids
  dots). The file under `bundles/` is named `<id>.prosaryprayer` so the apps' install scan
  derives the id from the filename.
- Bundles must pass the app's `installPack` checks; author them with
  [Prosary Compose](https://compose.prosary.app) (the seed bundle here was generated by
  `../Compose/scripts/make-repo-seed.ts` through the same pack code).
- Submissions: a pull request adding the bundle + its `index.json` entry.
