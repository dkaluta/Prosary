# Prosary 0.22.2 verification

Verified on October 17, 2026 from the isolated release snapshot, excluding unrelated Bible and Repository work.

Home now places natural-height cards in independent vertical columns. Saved order runs across columns from the native leading edge, by source index modulo column count; expanding a card moves only later cards in its column. One outer scrolling page serves each safe pane. The existing readable-width policy chooses one to three columns, while narrow panes retain one. Native RTL, card identity, stored accents, expanded state and the existing Apple iCloud arrangement contract are preserved. Column count remains local.
