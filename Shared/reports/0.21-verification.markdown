# 0.21 implementation and verification

Local pre-release verification on 14 October 2026. These checks preceded commit,
push and distribution; they are not a record of store availability. Unrelated staged
and checkout changes were preserved. The user requested Apple/Android release and
explicitly deferred the Windows release.

## Implemented behavior

| Request | Result |
| --- | --- |
| Small and large widgets | In-app Home cards have independently persisted compact/expanded state. Order, visibility, date and prayer progress remain independent. Operating-system widget families retain their existing sizes. |
| Calendar parity | iOS, Android and Windows use all supplied events, a Monday-first Gregorian month grid and shared window date selection. Dates show up to three dots with the complete accessible count. |
| Clickable events | Individual supplied observances open details with an exact-language source excerpt, prose and credits where available. Missing prose stays explicitly unavailable. |
| Custom accent | Device settings accept a custom color independently of the app icon. Native rendering adjusts lightness for readable contrast. Android manual selection disables system colors; Mac retains its system accent. |
| Graphics on cards | Home cards can add, replace and remove private image copies. Prayer cards use artwork from their owning pack. Failed replacement preserves the old private image and the original gallery photo. |
| Scripture of the Day | Holy Scripture and Home use the first Gospel in canonical appointment order, or the first appointment when no Gospel is supplied. Existing edition, citation mapping and offline text availability govern the reader. |
| Creed policy | Optional authored-source tags replace the Filioque toggle. Syriac and Mission clauses render in square brackets, Ukrainian preserves its source brackets, and Latin/Vicariate wording is unbracketed. |
| Apostles' Creed availability | Sources tagged as not praying it omit it from lists and shortcuts. Legacy devotion Creed steps and option labels use that same source's Nicene body and heading. Stale direct routes show a localized explanation and language selection. |
| Duplicate community Litany | Only `repo.stgamliel-il.litanyOfMaryTheBlessedEverVirgin` is retired. Updated apps reject/purge it and associated saved state. The built-in Litany of Loreto and the Rosary option remain. |

The Ukrainian Nicene text is transcribed from the 2012 UGCC catechism,
[Христос – наша Пасха, printed page 10](https://catechismugcc.org/doc/Catechism-UGCC.pdf).
Its exact text and PDF hash are pinned in the source fixture and credited in all native About screens.

The supplied Greek Creed contains no Filioque. The
[St. George Melkite source](https://stgeorgemelkite.org/resources/frequently-asked-questions/)
also describes omitting it, so a preferred unbracketed Melkite recension is still needed
before changing that supplied text. A
[Saint Maron parish source](https://www.saintmaron.ca/prayers/) confirms an unbracketed
Maronite form, but supplies no missing Syriac or Hebrew Maronite recension. Untagged
imported prayers retain their authored wording.

the optional Creed format validation, but performs no production deletion.
