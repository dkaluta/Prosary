# Prosary 0.24.0 verification

Prepared on 2026-10-28 from `feature/continuous-bible-pages`, based on
`fff927f154f3b2a0c350e14dd0d6eca5415b9177`. Android is 0.24.0 (63), Apple is
0.24.0 (local build 2400; Xcode Cloud assigns its own build number), and Windows is
0.24.0.0.

## Reader behavior

The whole installed edition forms one offline, justified document. Chapters and books
flow into the available page space. The global counter and slider expose the entire
edition; ordinary page turns reuse the prepared text without chapter loading spinners.
Native book, chapter and verse lookup preserves reviewed source addresses. Source notes
open separately from selectable Scripture. Source gaps, printed numbering and credits
remain visible; no canonical Scripture content or archive was changed.

Touch taps hide application navigation and reader controls on phones and tablets and
restore them on the next tap. Apple retains native glass when the bars are visible.
Desktop page buttons use compact sizing. Text selection, links and note disclosures retain
their own interactions. The renderer is copied byte-for-byte into all three native ports;
CI checks those copies.

## Distribution boundaries

Publishing targets the existing Play closed-alpha track and Apple TestFlight workflow and
groups. Upload, processing, internal availability and external review are separate states.
The GitHub prerelease receipt records the delivered commits and distribution states.
Windows requires its native CI checks; no Windows MSIX or physical fold qualification is
claimed by local Mac and simulator validation.
