# Prosary 0.23.1 release verification

Prepared on 2026-10-22 from `feature/bible-calendar-home-layout`, based on
`f8597a1930dafcf2719ec218d79d8a4cc9346ad3`. Android is 0.23.1 (61), Apple is
0.23.1 (local build 2301; Xcode Cloud assigns its own number), and Windows is 0.23.1.0.

## Changes

Holy Scripture opens full-screen on iPhone/iPad. Calendar grids follow the system calendar
and regional first weekday while retaining civil event identities. Home cards fill the
shortest available column. Tablet date pickers fit resized windows with reachable Today/Done
controls. Native pointer feedback and text-selection input are preserved, and Android reader
anchors no longer drift into scroll padding during resizing. Shared source text is unchanged.
