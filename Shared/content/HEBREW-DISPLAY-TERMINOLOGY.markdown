# Hebrew display terminology

On 2026-10-07 the user supplied the neutral prayer titles **שלום לך** and
**שבח לאב**, and named the Dominican Rosary **מחרוזת הורדים**. Prayer headings,
basic-prayer cards, Rosary options and interface labels use those titles. Hebrew
tradition choices use **נוסח לטיני** and **נוסח סורי** while retaining the stored
`he` and `he-x-gamliel` identities. Institutional names remain in source attribution
and the Mission calendar's provenance.

This is a display vocabulary change. The sourced prayer bodies, including their
original incipits, remain unchanged; no Hebrew liturgical wording or vowel points
have been invented. Saved personal prayer names remain the user's own names.
