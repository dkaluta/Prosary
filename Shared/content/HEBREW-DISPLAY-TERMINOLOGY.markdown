# Hebrew display terminology

On 2026-10-07 the user supplied the neutral prayer titles **שלום לך** and
**שבח לאב**, and named the Dominican Rosary **מחרוזת הורדים**. Hebrew
tradition choices use **נוסח לטיני** and **נוסח סורי** while retaining the stored
`he` and `he-x-gamliel` identities. Institutional names remain in source attribution
and the Mission calendar's provenance.

On 2026-10-18 the user specified that Hebrew — Vicariate prayer titles must use
the Vicariate wording: **שמחי מרים** and **כבוד לאב**. Basic-prayer cards and
devotion headings use those titles, including the combined Rosary heading
**שמחי מרים וכבוד לאב**. These titles carry Vicariate provenance in every
bundle that supplies them. Mission Hebrew retains its own **שלום לך מרים**
and **השבח לאב** headings; the other existing sourced titles retain their wording.

Hebrew Rosary option labels and spoken bead progress resolve prayer names from the
selected Hebrew tradition, just as the reader does. Changing the tradition refreshes
these labels; a different global default or fallback priority cannot rename an explicit
selection. Other interface languages retain their existing labels; Hebrew interfaces use
descriptive labels for non-Hebrew prayer languages. Portable option
metadata uses descriptive Hebrew labels where a static name cannot express the chosen
tradition. The Vicariate Anima Christi heading is **נפש המשיח**, matching its existing
prayer text and Stations heading, and carries Vicariate provenance in both bundles.

This is a display vocabulary change. The sourced prayer bodies, including their
original incipits, remain unchanged; no Hebrew liturgical wording or vowel points
have been invented. Saved personal prayer names remain the user's own names.
