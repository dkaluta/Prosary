# Android port notes — archived

This file originally planned the Android port before it existed. That port is complete and the
old plan no longer describes the product: it referred to fake backends, four languages, a
Rosary-only engine, and screens that have since been replaced.

Use the maintained sources instead:

- [`../AGENTS.md`](../AGENTS.md) — repository workflow and the three-way parity rule.
- [`../Shared/ARCHITECTURE.md`](../Shared/ARCHITECTURE.md) — the current cross-platform behavior
  and `.prosaryprayer` format.
- [`../Android/README.markdown`](../Android/README.markdown) — Android requirements,
  architecture, signing, and tests.
- [`README.markdown`](README.markdown) — the Apple implementation and its platform-specific
  services.

For a parity change, read the current iOS, Android, and Windows implementations of the subsystem;
iOS remains canonical only when the three genuinely disagree. Do not use this archived filename
as an implementation specification.
